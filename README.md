# N78-Public-Legal

**Canonical** public privacy and terms HTML for every Nivo78 product. Store listings, Play/Microsoft privacy URL fields, and in-app browser handoff must use these pages (not `nivo78.com/{slug}/privacy/`). The site also serves continuity if nivo78.com is unavailable.

## Files

Each product uses flat names under `pages/`:

- `{App display name}.privacy.html`
- `{App display name}.terms.html`

Example: `pages/N78-Machining.privacy.html`

## URL catalog (store listings)

**`docs/Legal URL.docx`** and **`docs/Legal URL.md`** — every GitHub Pages URL for this repo (regenerated by sync).

## Refresh from N78-Website (+ N78-APA for APA legal)

```powershell
pwsh -NoProfile -File tools/sync-from-n78-website.ps1
```

## GitHub Pages

Publish from branch `main`, folder `/` (root).
