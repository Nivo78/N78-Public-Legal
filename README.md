# N78-Public-Legal

**Canonical authority** for all Nivo78 public legal HTML (privacy, terms, operator disclaimer). The **`main`** branch of this GitHub repo is the sole source of truth; GitHub Pages is the published mirror. See `reference/CANONICAL_LEGAL_AUTHORITY.txt`. Store listings, Play/Microsoft privacy URL fields, and in-app browser handoff must use these pages (not `nivo78.com/{slug}/privacy/`). The site also serves continuity if nivo78.com is unavailable.

## Files

Each product uses flat names under `pages/`:

- `{App display name}.privacy.html`
- `{App display name}.terms.html`
- `{App display name}.operator.html`

Example: `pages/N78-Machining.privacy.html`

## URL catalog (store listings)

**`docs/Legal URL.docx`** and **`docs/Legal URL.md`** — every GitHub Pages URL for this repo (regenerated by sync).

## Full refresh (recommended)

```powershell
pwsh -NoProfile -File tools/refresh-public-legal-mirror.ps1
```

Runs, in order: `sync-from-n78-website.ps1` → `ensure-all-family-legal-pages.ps1` → critical provisions → cross-links → `write-legal-url-catalog.ps1`.

## Refresh from N78-Website only (+ N78-APA for APA legal)

```powershell
pwsh -NoProfile -File tools/sync-from-n78-website.ps1
```

## Ensure three pages for every family app (catalog from N78-Kit `family-apps.json` + N78-QRTest)

Creates **missing** privacy / terms / operator pages from `templates/` (does not overwrite existing website-synced privacy or terms):

```powershell
pwsh -NoProfile -File tools/ensure-all-family-legal-pages.ps1
```

## Family critical legal blocks (UCC, liability cap, venue, severability)

After editing individual product prose, re-apply the shared **Critical legal provisions** block to every file under `pages/`:

```powershell
pwsh -NoProfile -File tools/apply-family-critical-legal-provisions.ps1
```

Inserts or refreshes the marked HTML section (UCC conspicuous disclaimer, **$50 / 12-month** liability cap, Texas / Smith County venue, severability + merger across **privacy, terms, and operator**, CPA/attorney advice disclaimer).

## Cross-links (shared overlap between the three documents)

```powershell
pwsh -NoProfile -File tools/apply-legal-cross-links.ps1
```
